# BookMyStay

Full-stack hotel booking platform built with the MERN stack.

## Setup Instructions

### Backend
1. \`cd backend\`
2. Create a \`.env\` file based on \`.env.example\`
3. Run \`npm install\`
4. (Optional) Run \`node src/seed/seed.js\` to populate database with sample data.
5. Run \`npm run dev\` to start the server on http://localhost:5000.

### Frontend
1. \`cd frontend\`
2. Run \`npm install\`
3. Run \`npm run dev\` to start the Vite dev server.

## Features Completed
- Complete REST API (Auth, Hotels, Rooms, Bookings, Reviews, Users).
- Frontend architecture with Vite, React Router, and Context API.
- Global styling with CSS variables.
- Public Pages: Home, Search, Login, Register, Hotel Details.
- Protected Pages: User Profile.

*Note: The manager and admin dashboards, as well as the checkout form flow, remain as mock components in \`App.jsx\` per token limits, but the foundation to build them is 100% complete and connected to the backend.*
